# LING 5832 — Natural Language Processing

Coursework repository (Yiyuan Jia).

## Assignment 1: How many words do you know?

An empirical estimate of my Mandarin vocabulary size by stratified random sampling of
《现代汉语词典》（第7版）(70,414 entries). See
[assignments/A1/assignment1-part1.pdf](assignments/A1/assignment1-part1.pdf) for the report.

**Take the test yourself** (≈25 min, in Chinese, generates your own statistical report):

> **https://yiyuan1840.github.io/ling-5832/**

### How it works

- 360 entries sampled from 5 length strata (seed 5832 — every tester gets the same sample, so results are comparable)
- Two-stage judgment: self-rating from the bare written form, then verification against the revealed dictionary definition (catches overclaiming)
- The report estimates entries known under four operationalizations of "know" (self-report / receptive-lenient / receptive-strict / productive), each as a stratified total Σ Nₕp̂ₕ with 95% CIs
- Everything runs client-side; your data stays in your browser unless you export it
